# 使用指南

## 1. 准备输入

至少提供主题。可补充目标读者、页数、原始素材、参考图、署名，以及此次要文字、提示词还是实际图片。信息已在对话中给过时无需重复填写。

```text
主题：给小白介绍RAG
形式：一张知识图
重点：是什么、怎样工作、什么时候有用
署名：我的账号
本次输出：先给上图文案和生图提示词，等我确认再画
```

不要把页面数量固定为8张；单图可以独立解释一个概念，多图则根据内容组织。多个相关概念组成一篇时，首图应交代关系。

## 2. 使用完整文件夹

`SKILL.md`需要读取同目录下的模板和参考图片。只粘贴主文件仍能传达部分规则，但会丢失样张和检查工具。

Codex用户可以在客户端的skill列表中选择本skill，或按环境支持的方式使用 `$xiaohongshu-pastel-carousel`。当前安装位置与发现机制以[官方文档](https://learn.chatgpt.com/docs/build-skills)为准。安装后未出现时，可重新打开客户端或新建对话检查。

Windows手动安装：解压完整ZIP，将根目录重命名为 `xiaohongshu-pastel-carousel` 后，复制到当前客户端支持的用户级技能目录。不要保留多套同名目录。其他兼容工具按各自的Skill导入方法操作；工具调用方式可能需要适配，不保证不加修改即可生图。

## 3. 先确认文字，再做视觉

默认先提出适合科普的内容结构。你可以针对一页讨论：

```text
“是什么”写得太抽象，请重写定义，其他部分不要变。
```

```text
把举例和提醒删掉，改为核心价值。保留现有定义和工作流程。
```

```text
不要大改，在保持知识点的同时删掉啰嗦表达。
```

明确说“画出来”“直接生成”后，才进入对应范围的生图阶段。未经你授权，不发布笔记。

## 4. 改成自己的账号

公开版默认保留原作者的视觉基准。制作新图时，直接说：

```text
这次全部图片右下角署名用“我的账号”，不要用Summer聊AI。
```

AI应统一替换新图文案和提示词里的署名。仓库中的原始样张不需要更改，也不要把样张误当成自己的成品。若希望长期更换默认名称，可在自己的本地副本中同步修改 `SKILL.md`、`references/prompt-template.md` 和 `agents/openai.yaml` 的默认署名或说明。

## 5. 生成与验收

图片生成由所在环境的图片工具完成。Codex制作路径优先使用可用的内置图片工具和imagegen技能；本仓库没有附带imagegen实现。没有图片工具时，可以先完成准确文案与提示词，不能把“提示词写完”报告为“图片已生成”。

验收重点：

- 逐字核对标题、正文、英文和署名，不能遗漏限定条件。
- 检查箭头方向、包含关系和数字；不要暗示固定比例、层级或保证效果。
- 检查3:4实际像素比例、整套同尺寸、四周留白和手机可读性。
- 有问题优先局部修改，再检查整页，防止修正造成其他变化。

只改某几张时，把未修改的最终图片一起列入交付清单。不要因为某个文件夹版本号更大，就默认其中所有图片都是最新版。

## 6. 完成后应获得什么

单页：独立成图、上图文案与提示词、简短来源及验收记录。

多页：以上内容，加按顺序编号的图片、最终文件清单和便于下载的ZIP。图上不必塞入长链接；事实来源可以单独保存。

生成效果受模型、工具和素材影响。参考样张提供方向，最终结果需要检查，不承诺一次生成没有错字。
