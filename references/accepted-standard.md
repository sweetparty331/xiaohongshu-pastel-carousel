# 迭代依据与案例

来源：2026-10-10，Summer在“7个AI黑话”知识图文对话中逐轮确认。此文件保存工作方法和历史案例，不代表以后每篇都讲AI术语或必须8页。用户后续指令优先。

## 本轮固定下来的取舍

- 用户认可淡彩细线风、足够的信息量、严谨知识、简洁流畅的中文。
- “降低理解难度”不能演变成大量删知识。先解释清楚是什么，避免“能力底座”“配套系统”等没有展开的抽象话。
- 不为所有概念套同一模板、同一例子。周报不是必选案例；需要时选择最能解释该概念的例子。
- Agent页改为突出核心优势；Harness页突出工作管理、规则权限、流程与边界，同时保留运行支持；MCP页增加核心价值并删除举例和提醒；Skills页增加常见类型和好处，删除举例与概念区分。
- 上述是本篇各页结构的决定，不能变成所有未来页面都禁止例子或必须列四个好处。
- 曾要求着重号，后来明确改为淡色块；新要求覆盖旧要求。
- 讨论内容、确认提示词、授权生成是不同阶段；不能因之前曾说过“自动跑”而跳过本轮明确提出的文字讨论。

## 事实检查案例

| 旧说法或常见误导 | 更准确的处理 |
| --- | --- |
| 中文1—2字固定约等于1Token | 字数与Token数无固定换算比例，取决于分词规则；不要编造具体分词图 |
| 用Token越多，记性越短 | 分开解释用量、计费、上下文容量与输出上限；不编造简单因果 |
| 上下文是AI记住的全部内容 | 当前回答可参考的信息，不等于永久记忆；上传过不保证本次全可见 |
| Agent会独立把所有任务完成 | 选择行动、观察结果、继续调整；受工具与权限限制，必要时询问 |
| Harness只是安全带／规则，或只是抽象配套系统 | 用工作管理视角解释其范围；规则、权限、流程与运行支持需要讲清，不保证安全或正确 |
| MCP一次接入就无限扩展 | 统一连接规范、减少重复开发、促进兼容服务复用；不替代实际接入与授权 |
| Skills就是模型天生会的各种能力 | 本篇指Agent Skills：可复用的任务说明及资源，按需加载使用 |

如需重新核查AI概念，优先查看最新官方文档。历史使用过的一手材料：

- Agent Skills规范与介绍：https://agentskills.io/home
- MCP文档：https://modelcontextprotocol.io/docs/getting-started/intro
- Anthropic，Trustworthy agents in practice：https://www.anthropic.com/research/trustworthy-agents
- LangChain，The Anatomy of an Agent Harness：https://www.langchain.com/blog/the-anatomy-of-an-agent-harness

Harness在这些来源中的范围并不完全一致；不要机械拼接成唯一标准定义。事实来源记录和图片上的简洁文案分开保存。
