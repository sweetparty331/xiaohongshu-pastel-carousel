# 单页提示词模板

替换尖括号变量；最终提示词只保留本页需要的内容。原稿文案与图片文字一一对应，不把来源链接、审核批注或提示词指令印在图片里。

```text
Use case: infographic-diagram.
任务：为Summer聊AI制作一张小红书知识科普图文，面向小白。
画布：严格3:4竖图，<宽>×<高>像素，与同篇全部图片尺寸一致；单页，不是拼图。
输入图角色：<图1是风格参考／图2是编辑目标；哪些内容需要保留>。

视觉：纯白底，深蓝黑字，浅蓝、薄荷绿、少量浅黄，轻量二维细线插画。
强调：仅用文字背后的浅色块，不在字上或字下打点，不加星号或圈字。
排版：四边留白约5%—8%；标题、正文、插画、边框、署名都在安全区内。
中文黑体层级清晰，正文适合手机阅读，词组不拆开、不单字孤行。
插画不抢正文；模块对齐，行距和内边距均衡。
右下方版心内署名：Summer聊AI。

本页知识目标：<读者看完应理解的一件事>。
布局：<按实际信息决定定义区、工作过程、类型／价值卡片、总结等的位置与占比>。
图示关系：<节点、箭头方向、包含关系；没有流程时不强行画流程>。
重点色块词：<4—6组左右，按本页内容决定，不强行凑数>。

必须完整准确呈现的文案：
<标题>
<定义>
<各模块标题与正文>
<总结，如需要>
Summer聊AI

不变项：<局部编辑时写明已批准文案、布局、插画、尺寸等>。
本次只修改：<局部编辑范围；全新图则删去本条>。
禁止：擅加数字、承诺或术语，删除关键限定条件，错画流程，添加他人水印；
不要纸纹、颗粒、撕纸、厚重3D、霓虹背景、点状着重号。
```

## 首图关系总览

多概念主题的封面应同时给读者一条理解主线和正确关系图。先确认概念之间是包含、依赖、调用、单位还是并列分工；没有依据，不画成“七层”“等级”或每次都必须依次执行的步骤。

## 局部修正提示词

```text
仅修正<具体错误区域和内容>。
目标为<准确文字／箭头／边距>。
其他已确认文字、插画、色块、比例和署名保持不变。
输出仍为<宽>×<高>，严格3:4竖图。
```

修正后仍需检查整页。小改也可能造成文字或尺寸漂移。
